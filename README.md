# 🌟 Landing Page - HVAC, Plomberie & Domotique  

## 🚀 Description  
Ce projet est une **landing page dynamique et responsive** développée avec **React**. Il a pour but de présenter les services d'une entreprise spécialisée dans :  

✅ **Climatisation & Ventilation**  
✅ **Plomberie & Chauffage**  
✅ **Domotique & Smart Home**  

L'objectif est d'offrir une **expérience utilisateur moderne et fluide**, avec une navigation intuitive et une présentation claire des services proposés.  

---

## 🎨 Technologies utilisées  
- ⚛️ **React** - Frontend dynamique et réactif
